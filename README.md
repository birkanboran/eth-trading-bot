# ETH Trading Bot - GitHub Actions

15m MACD stratejisi ile Bybit ETH/USDT perpetual ticareti yapan bot.

## Kurulum

1. GitHub Secrets'e ekle:
   - BYBIT_API_KEY
   - BYBIT_SECRET_KEY
   - TELEGRAM_TOKEN
   - TELEGRAM_CHAT_ID

2. Bot her 15 dakikada otomatik çalışacak

## Özellikler

- 15m MACD sinyalleri
- Telegram bildirimleri
- Otomatik TP/SL
- PnL takibi
